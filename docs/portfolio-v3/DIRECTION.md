# Maxeem — продуктовая презентация

Задача: HR быстро узнаёт автора и специализацию; senior/lead видит реальные интерфейсы, сценарии и инженерный вклад. Название сайта — Maxeem, русское описание «Портфолио разработчика». Абстрактный бренд, спираль и метафорические лозунги удаляются.

Токены: холодный белый #f3f4f6, чернила #17191f, серый #626973, коралл #f36145, светлая сталь #dce1e6, ночной #101216. Onest: имя/роль и заголовки; Geist: текст; Geist Mono: статусы и технологические подписи.

Композиция: конкретная роль и имя → большое пространство реальных интерфейсов с видео → проекты широкими главами → краткий профиль и инженерные решения → стек → прямой контакт. Герой не является очередной стопкой карточек. Витрина меняется целиком: фон, экран, название и подпись сценария. Обложки и видео — только реальные приложения.

ASCII: [maxeem. / work / about / contact] [роль | краткое описание] [project title + BIG ACTUAL SCREEN + supporting mobile screen] [project selector / pause / case link] → [wide project chapter × 3] → [compact remaining work] → [engineering evidence / profile] → [contact].

Критика до реализации: один карусельный экран рядом с большой фразой повторил бы исходную слабость. Поэтому экран становится главным масштабным материалом, включает реальные действия и смену состояний; карточки первых трёх проектов раскрываются как отдельные сцены. Декоративная 3D-графика и генерированные скриншоты не используются. Логотип — специально набранный wordmark Maxeem с курсором, без выдуманного названия или аватарки.

Движение: запись реальных действий внутри продукта; согласованный переход экрана и фона; scroll reveal/scale крупных экранов; параллакс на desktop; появление новых страниц; смена темы. Нативная прокрутка, пауза, reduced motion, видео только в видимой области, статические постеры при сбое/экономии трафика, все смысловые действия доступны с клавиатуры и без видео.

Референсы: https://cuberto.com (проекты как основной визуальный материал), https://14islands.com (единая страница и крупные переходы между работами). Сторонние ассеты не копируются.
