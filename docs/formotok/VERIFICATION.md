# Формоток — проверка редизайна

17 октября 2026. Личное портфолио Maxeem.

## Реализовано
- Русское название Формоток, знак в форме непрерывной буквы «ф», favicon, заголовки страниц и OG.
- Новая композиция, Onest с кириллицей, ледяная светлая и тёмная синяя темы.
- Собственная хромированная 3D-лента: непрерывное движение, отклик на мышь и прокрутку. Three.js загружается отдельно, DPR ограничен 1.5, рендер приостанавливается за пределами экрана и в скрытой вкладке; ресурсы освобождаются при уходе со страницы.
- Пауза декоративной анимации, prefers-reduced-motion, изображение при недоступном WebGL, серверный контент без JavaScript.
- Крупные экраны настоящих проектов, фильтры, появление при прокрутке, пространственный hover, арт-переход в разделе автора, единое оформление всех восьми кейсов.
- Сохранены реальные сведения, контакты, демо/код, RU/EN, галереи, клавиатура и переходы между кейсами.

## Исправлено при проверке
- Canvas выходил за ширину экрана: сцена ограничена собственным контейнером.
- Canvas перехватывал клик по паузе: декоративный слой не принимает pointer events.
- OG-генератор не принимал новый variable font: карточка ссылки теперь заранее отрендерена, HTTP 200 без runtime-зависимости от шрифта.
- Тест мобильного canvas делал снимок вне видимой области: проверка движения теперь снимает фактически видимую часть сцены; движение подтверждено на двух кадрах.

## Границы проверки
Телефон проверен через Chrome с мобильным viewport и touch, не на физическом устройстве. Safari и Firefox не запускались. Внешние приложения не перерабатывались: в портфолио сохранены пояснения о запуске Render, недоступном публичном ReplayLab и ограничениях облачного VariantLab. Название проверено открытым поиском, юридическая чистота товарного знака и домен не подтверждены.
