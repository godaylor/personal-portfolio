## Проверка текущего Portfolio

- Lint, MDX smoke, TypeScript/production build и audit production dependencies.
- Chromium, Firefox и WebKit: RU/EN, 16 project routes, blog empty state,
  metadata/JSON-LD, ссылки, 404, возврат к списку, Назад/Вперёд и reload.
- Светлая/тёмная тема, сохранение выбора, меню и якоря без перекрытия шапкой.
- Keyboard: skip link, видимый focus, кнопки; в Windows WebKit штатный Tab
  перебирает form controls, поэтому skip link дополнительно проверен через
  программную установку фокуса и Enter. Escape не открывает/не требует тура.
- Clipboard: успешная запись проверена чтением в Chromium; отказ — отдельным
  контекстом во всех движках. Email выделяется целиком без изменения адреса.
- Изображение, недоступное по сети: понятный fallback, описание и действия доступны.
- Ширины 320/360/390/430/639/640/759/760/761/768/820/959/960/961/1024/1280/1440/
  1920/2560/3840/5120/7680 CSS px, обе локали и темы: без горизонтального
  переполнения или разрыва слов. Текст увеличен до 200%; проверены эффективные
