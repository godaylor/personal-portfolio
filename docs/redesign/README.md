# Maxeem — Interface meets logic

## Задача и концепция

Портфолио frontend / full-stack разработчика для работодателя. Главная задача: за один экран объяснить специализацию, показать реальные интерфейсы, дать быстрый путь к приложению и коду.

В исходном сайте материалы были собраны в однородный список. В новой версии работы идут сразу после вступления, затем личная подача, технологии и контакты.

### Визуальная система

- Фон #F8F9FB; текст #252638; лавандовая поверхность #EFEBFA; фиолетовый акцент #5C46AD; мятный #DCEEE5; голубой #DFE9F5.
- Geist для интерфейса и крупного заголовка; Georgia italic для смыслового акцента; Geist Mono для компактных технических подписей. Шрифты не требуют внешних запросов.
- Композиция: крупное вступление + интерактивная стопка реальных экранов; первый проект на всю ширину; далее двухколоночная галерея; на телефоне одна колонка.
- Фирменный элемент: стопка интерфейсов, раскрывающаяся при наведении и переключаемая кнопками. Это прямое представление предмета работы, а не отвлечённый декоративный объект.
- Первоначальная идея абстрактной 3D-иллюстрации заменена реальными экранами: они лучше подтверждают содержание портфолио. Изображения не генерировались и не подменяют реальные результаты.

### Референсы

- https://linear.app — крупная типографика, реальные интерфейсы как главные визуальные материалы; просмотрены интерактивная витрина и изменение её состояния.
- https://bruno-simon.com — идея портфолио как исследования работ через взаимодействие. В этой реализации выбран короткий доступный путь через кнопки и обычную прокрутку.
- https://lucasvallenet.com — изучена подача портфолио разработчика, специализирующегося на движении и взаимодействии.

Применённые навыки: frontend-design и vercel-react-best-practices. Изображения, тексты проектов, ограничения доступа, контакты и исходные ссылки взяты из существующего репозитория.

## Реализация

- Обновлены главная страница, все 8 страниц проектов, блоки технологий и контактов, favicon и Open Graph.
- Витрина из 3 проектов с циклическими кнопками, поддержкой клавиатуры и резервным содержимым при недоступном изображении.
- Фильтры: все работы, инструменты, магазины, аналитика. В разработке остаётся отдельный блок VariantLab / LifeOS Social.
- Общая светлая и тёмная палитра; русская и английская версии.
- Переход к следующему проекту в конце каждого кейса.
- Движение: появление вступления, раскрытие стопки, смена экрана, hover превью, появление карточек при прокрутке в поддерживающих браузерах, появление секций. Нет захвата прокрутки или автоматического переключения слайдов.
- Reduced motion отключает движение. Серверный HTML доступен без JavaScript. Исправлена гидратация прежнего BlurFade при reduced motion.
- Добавлена проверка локали перед чтением данных страницы; некорректные параметры не передаются в коллекцию проектов.
- Исправлен запрос браузера к отсутствовавшему favicon.ico: добавлена ICO-версия фирменной иконки. Именно этот запрос вызывал фоновый 500 в исходной обработке неизвестной локали.

## Проверки

- Production build и TypeScript: успешно.
- ESLint и MDX-проверка: успешно.
- Основной browser suite: 20 маршрутов RU/EN, все ссылки проектов, 22 ширины от 320 до 7680 CSS px, две темы, переполнение, якоря, клавиатура, история, смена языка, копирование почты и отказ clipboard, недоступные картинки, 404, sitemap, robots и Open Graph.
- Gallery suite: все 8 кейсов на двух языках; миниатюры, увеличение, Escape, фокус, смена тем, адаптивность, перезагрузка, история, недоступные изображения.
- Новый verify:redesign: desktop 1440 px и мобильная touch-эмуляция 390 px, обычное движение, полный цикл витрины, все фильтры, прокрутка до каждой секции, темы, переход к следующему кейсу, язык; отдельно 320 px / reduced motion / отключённый JavaScript.
- Скриншоты визуально просмотрены: главная, проекты, обо мне, контакт, мобильный кейс, тёмная тема.

Проверки телефона проводились в Chromium с мобильной эмуляцией и touch. Физический телефон и Safari не использовались.

## Запуск и материалы

Production preview: http://127.0.0.1:32801

```powershell
pnpm build
pnpm exec next start --hostname 127.0.0.1 --port 32801
# В другом терминале:
$env:PORTFOLIO_BASE_URL='http://127.0.0.1:32801'
pnpm verify:browser
pnpm verify:presentations
pnpm verify:redesign
```

comparison.html — переключаемое сравнение desktop/mobile. comparison.png — статическое сравнение. before-* — исходный сайт, after-* — итоговая production-версия. Остальные PNG показывают отдельные разделы и состояния.

## Границы

Публичный deployment не обновлялся. Серверы отдельных проектов не изменялись: исходные пометки о sleep бесплатного хостинга, демонстрационных покупках и недоступном ReplayLab сохранены. Резюме, фотография, работодатели и опыт не выдумывались. Внешние облачные функции проектов не проходили новый полный аудит в рамках визуального редизайна портфолио.
