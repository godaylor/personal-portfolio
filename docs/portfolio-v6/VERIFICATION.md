| Дежурно | Публичный адрес несколько раз вернул HTTP 503 и страницу Render «Application loading». Повторный запрос также завершился тайм-аутом. Текущий интерфейс подтвердить не удалось. Сохранены прежние проверенные экраны v4 с явной пометкой; страница загрузки не выдана за экран приложения. |

Свежие JPEG и MP4 имеют новые имена `v6-*`, поэтому старый кеш браузера/CDN не подменяет обновление. Новые названия приложений не придумывались: видимые бренды публичных версий остались прежними.

- 32 сочетания кейс × RU/EN × desktop/mobile — PASS; 24 уникальных JPEG галерей, 64 контрольных снимка, без ошибок JavaScript и горизонтального переполнения. Результаты: [current-media-report.json](final/current-media-report.json).
