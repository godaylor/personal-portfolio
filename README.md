# Maxeem Portfolio

Clean, standalone foundation for a personal portfolio. Personal content, project
details, links, and media are intentionally left as placeholders until they are
provided and approved by the owner.

## Local development

Requirements: Node.js 18 or newer and pnpm.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Quality checks:

```bash
pnpm lint
pnpm build
```

Before publishing, replace the placeholder site URL, review metadata, and add
only verified owner-provided content.
