# Geist fonts

Unmodified variable fonts downloaded on 2026-09-28 from the official Google Fonts repository:

- https://github.com/google/fonts/blob/main/ofl/geist/Geist%5Bwght%5D.ttf
- https://github.com/google/fonts/blob/main/ofl/geistmono/GeistMono%5Bwght%5D.ttf

Both use the included SIL Open Font License, `OFL.txt`.
Local hosting preserves the existing font families and removes build-time Google Fonts requests.
